Debouncing & Throttling

  Debouncing and throttling are two common optimization techniques in frontend development.

  Debouncing:

      Debouncing delays the execution of a function until a specified amount of time until since last the event occured.

      User typing in a searchbox

      h
      he 
      hel 
      hell 
      hello

      - Without debouncing : API Call is made for each letter is typed
      - With debouncing    : API call is made after 500 ms, once the typing is stopped.

      implementation:

      function debounce(func, delay) {
          let timer;

          return function (...args) {
              clearTimeout(timer);

              timer = setTimeout(() => {
                  func.apply(this, args);
              }, delay);
          };
      } 

      function search(value) {
            console.log("Searching:", value);
        }

        const debouncedSearch = debounce(search, 500);

        input.addEventListener("input", (e) => {
            debouncedSearch(e.target.value);
      });

   Throttling: 

    - Throttling ensures a function is executed at most once every specified interval, regardless of how many events occur.
    - Execute at regular interval

    Example: 

    - When a user scrolls continously 
    - Without throttle : hundreds of function call occurs every second
    - With throttling  : the function executes only once every 500ms

    Implementation:

    function throttle(func, delay) {
        let lastCall = 0;

        return function (...args) {
            const now = Date.now();

            if (now - lastCall >= delay) {
                lastCall = now;
                func.apply(this, args);
            }
        };
    }

    function handleScroll() {
        console.log("Scrolling...");
    }

    const throttledScroll = throttle(handleScroll, 500);

    window.addEventListener("scroll", throttledScroll);
